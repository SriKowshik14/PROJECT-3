# Heart Rate Monitor with OLED

## Project Overview

This project is a browser-based simulation of a heart-rate monitor display inspired by an OLED screen. When the user presses the **Measure** button, the page generates and displays a sample heart-rate value.

This is a user-interface demonstration only. It does not measure a person's pulse, connect to an OLED module, or provide medical readings.

## Features

- OLED-style display in the browser.
- Measure button generates a simulated reading.
- Displays the simulated value in beats per minute (BPM).
- Animated heart icon after a reading is generated.
- Responsive layout for smaller screens.

## Technologies Used

- HTML
- CSS
- JavaScript

## Project Files

Heart-Rate-Monitor-OLED/

How to Run
1. Save the project code as index.html.
2. Save this README as README.md in the same folder.
3. Open index.html in a web browser.
4. Click Measure to display a simulated value.
You can also open the folder in Visual Studio Code and use the Live Server extension.
How It Works
JavaScript generates a demonstration value between 60 and 100 BPM when the button is clicked. It updates the display and starts the heart animation. CSS provides the OLED-style colors and device appearance, while HTML defines the display and button.
Possible Hardware Version
A hardware version could use a microcontroller, a pulse sensor, and an OLED display. The sensor reading would need to be processed by the microcontroller and sent to the display. That hardware setup is not included in this browser simulation.
